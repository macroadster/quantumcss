What is QuantumCSS?

A modern, performance-optimized utility-first CSS framework with semantic naming and component-aware utilities.

Do I need a build step?

No. One link tag and you're done. Optional CLI for theming.

Is dark mode automatic?

Yes. It follows prefers-color-scheme by default, with manual override via data-theme.
